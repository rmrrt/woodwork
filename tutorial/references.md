# Нормативы и литература

## Главные нормативные документы РФ

### Каркас и деревянные конструкции

- **СП 31-105-2002** «Проектирование и строительство энергоэффективных одноквартирных жилых домов с деревянным каркасом». Главный документ по platform framing в РФ.
- **СП 64.13330.2017** «Деревянные конструкции» (актуализированная редакция СНиП II-25-80). Расчёт несущих элементов.
- **ГОСТ 32567-2013** «Плиты древесные с ориентированной стружкой (OSB). Технические условия».
- **ГОСТ 20850-2014** «Конструкции деревянные клееные. Общие технические условия».
- **ГОСТ 30974-2002** «Соединения деревянных конструкций угловые. Методы испытаний на несущую способность».
- **ГОСТ 33080-2014** «Конструкции деревянные. Классы прочности конструкционных пиломатериалов и методы их определения».

### Пиломатериал

- **ГОСТ 8486-86** «Пиломатериалы хвойных пород. Технические условия». Сорта 1–4 для каркаса.
- **ГОСТ 24454-80** «Пиломатериалы хвойных пород. Размеры».
- **ГОСТ 26002-83** «Пиломатериалы хвойных пород северной сортировки, поставляемые для экспорта. Технические условия».
- **ГОСТ 8242-88** «Детали профильные из древесины и древесных материалов для строительства» (вагонка, плинтус и т.п.).
- **ГОСТ 6782.1-75** «Пиломатериалы хвойных пород. Величины усушки».
- **ГОСТ 6564-84** «Пиломатериалы и заготовки. Правила приёмки, методы контроля, маркировка и транспортирование».
- **ГОСТ 17005-82** «Конструкции деревянные клееные. Метод определения водостойкости клеевых соединений».

## Книги и практические руководства

### Конструкция и расчёт

- **Larry Haun** — *The Very Efficient Carpenter*. Базовая книга по platform framing, краеугольная для практической каркасной школы.
- **Roger W. Harris** — *Working Alone*. Сборник приёмов одиночной работы плотника.
- **Robert J. Scharff** — *The Complete Book of Framing*. Подробный иллюстрированный гид.
- **Joseph Lstiburek** — *Builder's Guide to Cold Climates*. Лучшая книга по физике конструкций в холодном климате.
- **Каменев Б. С., Малахов Г. М.** — *Деревянные конструкции в современном строительстве*.

### Изоляция и физика

- **Lstiburek J., Carmody J.** — *Moisture Control Handbook*. Влажностный режим в стенах, точка росы.
- **Hutcheon N. B., Handegord G. O. P.** — *Building Science for a Cold Climate*. Учебник.

### Бани

- **Хошев Ю. М.** — *Теория бани*. Систематический разбор русской бани.
- **Mikkel Aaland** — *Sweat: The Illustrated History and Description of the Finnish Sauna*. Скандинавская традиция.

### Российские самостройщики

- **Андрей Шанин** — серия книг по каркасному строительству. Практические приёмы.
- **Лалл Александр** — *Каркасный дом своими руками*.
- Канал **«FORUMHOUSE»** — не книга, но архив бесплатных материалов уровня учебника.

## Онлайн-ресурсы

- **forumhouse.ru** — крупнейший форум по самострою в РФ. Темы по каждому модулю этого курса.
- **diy.ru / mastergrad.com** — инструмент и практика.
- **buildingscience.com** (Lstiburek) — мировой гуру по физике стен.
- **finehomebuilding.com** — журнал про современный американский каркас.
- **YouTube: Matt Risinger / Build Show / Essential Craftsman** — англоязычные каналы с расчётом, но идеи переносимы.
