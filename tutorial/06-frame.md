# Модуль 06. Каркас стен (platform framing)

Здесь мы собираем «скелет» дома. Платформенный каркас работает по принципу: построили перекрытие → собрали стены лёжа → подняли → следующий этаж стоит на коробке как на платформе.

## 6.1. Архитектура каркасной стены

Сверху вниз стена состоит из:

```
┌─ Верхняя обвязка (обычно сдвоенная)
│
│   ┌─ Хедер/ригель над проёмом
│   │
│   ┌─ Cripple stud (короткая стойка над/под проёмом)
│   │
│   Стойка   Силовая (king) стойка проёма
│   │           │
│   │           ┌─ Trimmer stud (короткая стойка под хедер)
│   │           │
└─ Нижняя обвязка (одинарная или сдвоенная)
```

Стандартный шаг стоек **600 мм**, но 400 мм используется:
- В районах высокой снеговой нагрузки.
- Под тяжёлой кровлей (натуральная черепица).
- В двухэтажных стенах первого этажа.

Шаг 625 мм — это дюймовая раскладка под лист OSB 4×8 футов. У нас 600 мм (под отечественные плиты 1200×600).

## 6.2. Нижняя обвязка

Это первый деревянный элемент дома. Здесь начинается геометрия.

### Материал и подготовка

- Сечение: 50×150 (под стойки 50×150) или 100×150.
- Порода: лиственница или антисептированная сосна.
- Влажность: 14–18 %.
- Двойная пропитка антисептиком в зоне водяных пятен.

### Технология укладки

1. Поверх ленты/ростверка/свайного оголовка — **гидроизоляция**: 2 слоя рубероида или гидростеклоизола, шире обвязки на 50 мм с каждой стороны.
2. Раскладка обвязочной доски по периметру и под несущими стенами.
3. **Угловое соединение**: «вполдерева» (вырезка половины сечения каждой доски) или встык с накладкой металлической пластиной 200×100 мм, либо с накладной короткой обвязкой второго слоя через угол.
4. Сверление отверстий под закладные шпильки М12. Сверло Ø14 мм (запас для подгонки геометрии).
5. Крепление: шпилька + шайба ⌀40 + гайка с моментом 70–80 Нм.

### Контроль геометрии

Это тот момент, когда ошибка в 5 мм становится 5 см на стене. Меряем:

- **Длины стен** по периметру с допуском ±5 мм.
- **Диагонали прямоугольника** — обе должны совпасть с допуском ±10 мм.
- **Горизонтальность** уровнем длиной 2 м, отклонение ≤ 2 мм/м.
- **Параллельность** противоположных стен (расстояния в углах и середине).

Если что-то не сходится — корректируем **сейчас**, до того как поставили хоть одну стойку.

## 6.3. Сборка стенной рамы (лёжа)

Принцип platform framing: стена собирается на платформе перекрытия (или ровной площадке), затем поднимается и крепится. Это безопаснее, точнее и быстрее, чем «стойка к стойке вертикально».

### Раскрой и разметка

1. На длинной доске (будущая нижняя обвязка стены) рулеткой и угольником размечаем:
   - Углы стены (каждый угол = силовая сдвоенная стойка).
   - Положение проёмов (с запасом по 100 мм на сборку).
   - Шаг 600 мм между остальными стойками.
2. Аналогичную разметку дублируем на верхней обвязке — обе доски лежат рядом, разметка через угольник одновременно. Так стойки гарантированно вертикальны.
3. Помечаем стойки маркером:
   - **K** — king (силовая стойка проёма).
   - **T** — trimmer (короткая под хедер).
   - **C** — cripple.

### Сборка

1. Раскладываем стойки между размеченными обвязками.
2. **Прибиваем гвоздями через обвязку в торец стойки**: по 2 гвоздя 4,5×120 мм с каждой стороны.
3. Над и под проёмами вставляем хедер и cripples.
4. Собранную раму проверяем по диагоналям — должны совпадать. Если нет — раму «гнём» по диагонали и временно фиксируем раскосной доской.
5. Прибиваем ветроизоляцию или предварительный лист OSB-3 на одну сторону рамы — стена становится жёсткой.

### Подъём и установка

1. Подъём вдвоём (стена 4–5 м) или вчетвером (стена 6–8 м).
2. Стена ставится на нижнюю обвязку **точно по разметке**, с учётом припуска 50 мм на торец на углу (для стыковки с перпендикулярной стеной).
3. Временные подкосы 50×100 от стены к обвязке/полу — без них стена упадёт от ветра.
4. Когда стоят все стены, проверяем вертикаль каждой стойки уровнем, корректируем подкосами.
5. Скрепляем углы между стенами: гвозди 4,5×120 в шахматном порядке через стойку угла.

### Верхняя обвязка

Платформенный каркас требует **сдвоенной верхней обвязки**:

- Первый ряд — это уже собранная верхняя доска рамы.
- Второй ряд кладётся **со сдвигом**: продольные стыки в первом и втором ряду должны быть в разных местах (минимум 600 мм между стыками). Это распределяет нагрузку и связывает стены в углах.
- Гвоздями 3,5×90 мм с шагом 400 мм.

Если есть фермы/балки 2-го этажа — они опираются на верхнюю обвязку.

## 6.4. Углы

Угол — это узел, где встречаются две стены. Варианты:

### «Калифорнийский угол»

```
План:
┌──┬──┐
│  │  │  ← 3 стойки 50×150, образуют угол с
│  │  │     карманом для утеплителя изнутри
└──┴──┘
```

3 стойки, образующие L-форму. Между ними остаётся пространство, которое утепляется. Минус — сложнее обшивать изнутри.

### Угол с заполнением

```
План:
┌─── 4 стойки: 2 силовых на каждой стене,
│ █  плюс заполняющие 50×50 для крепления
│ █  внутренней отделки. Утепление по
└────  межстоечным карманам.
```

Это более «расхожий» вариант для самостроя. Используется в большинстве проектов.

Принцип одинаковый: **в углу не должно быть «пустоты» или сплошного бруса 150×150**, потому что:
- Сплошной брус — мостик холода.
- Пустота — нечего изолировать.

## 6.5. Проёмы под окна и двери

Стандартный узел:

```
┌─────────────────────┐
│       Cripples       │  ← короткие стойки от хедера до верхней обвязки
├─────────────────────┤
│                     │
│       Хедер         │  ← ригель, например 2×50×150 + OSB 9 мм между
│      (header)       │
├──┬───────────────┬──┤
│T │               │T │  ← Trimmer stud (опирает хедер)
│  │   ОКНО         │  │
│  │   проём        │  │
│  │               │  │
│K │               │K │  ← King stud (силовая, идёт от низа до верха)
├──┴───────────────┴──┤
│       Cripples       │  ← подоконные короткие стойки
└─────────────────────┘
```

### Размеры проёма

Размер «в свету» (отверстия в каркасе) = размер окна по коробке + 30 мм с каждой стороны (на монтажную пену + допуск). То есть на окно 1200×1500 проём должен быть ~1260×1560 мм.

### Хедер

Хедер опирается на trimmer'ы и переносит нагрузку с верхней обвязки/перекрытия на silover стойки. Сечение и тип — по таблице из модуля 04.

### Сборка

1. На нижнюю обвязку прибиваем king stud (от низа до верха).
2. К нему рядом — trimmer stud (короче, до низа хедера).
3. На две trimmer'а опираем хедер.
4. Над хедером ставим cripple stud с шагом 600 мм до верхней обвязки.
5. Под подоконником (если окно) — cripple stud от нижней обвязки до подоконного бруска с шагом 600 мм.

## 6.6. Внутренние стены и перегородки

Несущие внутренние стены — то же сечение, что и наружные (50×150) или 50×100 (если не несут перекрытие). Шаг 600 мм.

Не несущие перегородки:

- Сечение 50×100 или 50×75.
- Шаг стоек 400–600 мм.
- Только нижняя и верхняя обвязка одинарные.
- В местах крепления тяжёлой мебели (ТВ-кронштейн, шкафы) — заранее закладные доски 25×150 между стойками.

### Узел «внутренняя стена ↔ наружная стена»

Между стойками наружной стены вставляются два бруска 50×100 под крепление гипсокартона перпендикулярной стены. Это «T-junction».

## 6.7. Жёсткость каркаса: диафрагма и раскосы

После сборки рам стен каркас **обязательно** жёстко фиксируется. Варианты:

### Обшивка плитой OSB-3 (главный вариант)

- Лист 9–12 мм OSB-3 (или ОСП-3 по ГОСТ 32567).
- Гвозди ёрш 2,8×60 или 3×70 мм.
- Шаг гвоздей: 100 мм по краю листа, 200 мм по полю.
- Стыки листов с разбежкой (не «крестом»), на стойках.
- Между листами зазор 3 мм (компенсация расширения).

Это превращает каркас в монолитную диафрагму, которая воспринимает горизонтальные нагрузки (ветер, сейсмика).

### Раскосы

В упрощённых проектах вместо OSB ставят раскосы из доски 25×100, врезанные в стойки под 45°. Не самый расчётный вариант, но работает на хозблоках и бытовках. Узел:

1. На стойках чертим линию под 45°.
2. Циркуляркой делаем пропилы на глубину 25 мм + стамеска.
3. Раскосная доска вставляется заподлицо, прибивается двумя гвоздями к каждой стойке.

В одной стене должны быть **два встречных раскоса** (V или X), либо один на каждой стороне.

### Анкерные связи (HD-анкеры)

В критических узлах (углы дома, силовые стойки больших проёмов) — **HD-анкеры (hold-down)**. Это специальный соединитель, который связывает между собой нижнюю обвязку, силовую стойку и фундамент через шпильку. В ураганных и сейсмических регионах обязательны (СП 14.13330 — сейсмика).

## 6.8. Звукоизоляция в межкомнатных стенах

Каркасник по умолчанию плохо изолирует звук. Если хочется тишины (спальня, детская):

- Перегородка 50×100 + минвата плотностью 50 кг/м³ толщиной 100 мм.
- ГКЛ в 2 слоя с обеих сторон + виброразвязка (упругие подвесы).
- Обвязки на демпферной ленте (не «доска на доске»).

Или классический «двойной каркас»: две независимые стенки 50×100 на расстоянии 30 мм с минватой 130 мм.

## 6.9. Стандартные ошибки

1. **Стойки прибиты «как получилось»**, шаг гуляет 580–620 мм. Лист ОСП не садится, плита утеплителя болтается. → Размечаем шаг на обеих обвязках одновременно.
2. **Угол собран впритык, без утеплительного кармана**. Промерзает зимой. → Калифорнийский угол или с заполнителем.
3. **Хедер слабый**. Через год прогибается, окно не закрывается. → Считаем по таблице.
4. **OSB прибит редко, шаг 250+ мм**. Стена «дышит», диафрагма не работает. → 100/200 строго.
5. **Стена собрана «вертикально, по месту»**. Стойки в разнобой, не в плоскости. → Только лёжа на платформе.
6. **Не успели поставить раскосы/обшивку — ветер свалил**. → Никогда не оставляем стены без подкосов на ночь.

## 6.10. Чек-лист сборки коробки

- [ ] Нижняя обвязка ровная, в горизонтали, на гидроизоляции, на закладных шпильках.
- [ ] Стойки вертикальны (отвес/лазер), шаг точный.
- [ ] Все проёмы с king + trimmer + хедером + cripples.
- [ ] Углы выполнены тёплыми (калифорния или с заполнителем).
- [ ] Сдвоенная верхняя обвязка со смещением стыков.
- [ ] Стены жёстко связаны между собой и обшиты OSB-3 или раскосами.
- [ ] HD-анкеры в углах и силовых стойках (если в проекте).
- [ ] Геометрия дома по диагоналям и уровням сходится.
